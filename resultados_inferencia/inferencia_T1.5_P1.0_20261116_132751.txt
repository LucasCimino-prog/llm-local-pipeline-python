Em primeiro lugar, eu vou te dizer o que é uma Arvore binaria de busca (BST). Uma BST é uma árvore binária em que, cada nó tem no máximo duas filhos e seus sub-árvores esquerdos contêm apenas números menores, e os sub-árvores direitos podem apenas conter números maiores.

```python
class Node:
    def __init__(self, val):
        self.val = val 
        self.left_child = None 
        self.right_child = None 

def check_bst(node, l_limit = float('-inf'), r_limit  =float('inf')):
    ''' 
        Checks if every node of a binary search tree
        has a value greater than its 'max_left_sub' value, and lesser than 
        max_right_sub value
        
        Return -->  boolean True iff every node value satisfies max_left_sub < current < max right_sub
        Time --> O(n)
        Space --> 0(n) where n --> maximum breadth (i.e., longest straight chain from node)
    '''

    # Empty Binary search tree is valid BSt therefore
    if node is None:
        return True
    
    # a valid Bst node's value must be greater than its 
    # lower and upper boundary
    if node.val <l_limit or node.val > max(l_limit, node.val):
        return False 

    # For a current node at `level, ` its left and right 
    # nodes would have a maximum value to the left
    # and minimum value from the right. Thus, left child of any current level nodes only
    # need to lie in lower to cur_node value range and vice versa
    return check_bst(node.left_child,l_limit, node.val) and check_bst(node.right_child, node.val,r_limit)
```
